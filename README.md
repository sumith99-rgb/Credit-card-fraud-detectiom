# Credit Card Fraud Detection

**Credit Card Fraud Detection using Statistical Analysis and XGBoost**

## Project Overview

The aim of this project is to detect credit card fraud using Statistical Analysis, Exploratory Data Analysis (EDA), and Machine Learning.

## Problem Statement

Credit card fraud is a huge issue when dealing with digital transactions. By analysing patterns of transactions, a classification model has been developed to identify fraudulent transactions.

## Dataset

- **Dataset Name:** Credit Card Fraud Detection
- **File Name:** `fraudTest.csv`
- **Number of Records:** 555,719
- **Number of Columns:** 23
- **Target Variable:** `is_fraud`
